# Nocturne Circuit — Gothic × Cyberpunk OpenType (.otf) Display Font Family

An original 2-style Latin display typeface fusing medieval Gothic pointed arches and dramatic vertical contrast with 45° cyberpunk PCB chamfers and split-stem circuit geometry.

## Download Working `.otf` Files
- **Expressive Hero Display:** [`NocturneCircuit-Hero.otf`](https://raw.githubusercontent.com/AndreyJackKali/nocturne-circuit-font/main/NocturneCircuit-Hero.otf)
- **Website & Mobile Heading:** [`NocturneCircuit-Heading.otf`](https://raw.githubusercontent.com/AndreyJackKali/nocturne-circuit-font/main/NocturneCircuit-Heading.otf)
- **Full Visual Specimen:** [`nocturne_circuit_specimen.png`](https://raw.githubusercontent.com/AndreyJackKali/nocturne-circuit-font/main/nocturne_circuit_specimen.png)

## Supported Character Set (77 Glyphs — Basic Latin Display Set)
- **Uppercase:** `A–Z` (26)
- **Lowercase:** `a–z` (26)
- **Numerals:** `0–9` (10)
- **Punctuation & Symbols:** `space . , : ; ! ? - _ / + ' " # &` (15)
- *Scope note:* Basic Latin display character set (accented/diacritic Latin-Extended characters and non-Latin scripts are not included in v1.0).

## Quick Website `@font-face` Setup
```css
@font-face {
  font-family: 'Nocturne Circuit Hero';
  src: url('./NocturneCircuit-Hero.otf') format('opentype');
  font-weight: 700;
}
@font-face {
  font-family: 'Nocturne Circuit Heading';
  src: url('./NocturneCircuit-Heading.otf') format('opentype');
  font-weight: 600;
}
```
